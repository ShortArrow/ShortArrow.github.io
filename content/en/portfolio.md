### icscli (formerly makeholiday)

![icscli icon](/img/portfolio/pending.svg)

A command-line tool for building and editing iCalendar (`.ics`) files, designed for managing personal holiday and event calendars from the terminal.

[https://github.com/ShortArrow/makeholiday](https://github.com/ShortArrow/makeholiday)

### gitreant

![gitreant icon](/img/portfolio/gitreant.svg)

A web app to manage, inspect, and maintain multiple local Git repositories from one place. It shows commit graphs side by side, supports branch operations and diff viewing, and ships as a single Rust binary.

[https://github.com/ShortArrow/gitreant](https://github.com/ShortArrow/gitreant)

### herdr-triton

![herdr-triton icon](/img/portfolio/herdr-triton.svg)

### CRC Visualizer

![CRC Visualizer icon](/img/portfolio/crc-visualize.svg)

An SPA that visualizes one clock of an LFSR (hardware) alongside one line of a bitwise CRC implementation (software). It supports switching CRC configurations using the Rocksoft model.

[https://crc.shortarrow.jp/](https://crc.shortarrow.jp/) / [https://github.com/ShortArrow/crc-visualize](https://github.com/ShortArrow/crc-visualize)
