# Privacy Policy

This site (www.shortarrow.jp) uses Cloudflare Web Analytics to learn which pages are read and how often.

## How it measures

This site is served through Cloudflare. Cloudflare inserts a measurement script (`https://static.cloudflareinsights.com/beacon.min.js`) into the pages it serves, and the script sends Cloudflare figures such as how long the page took to load.

## What is collected

Cloudflare Web Analytics shows me aggregate figures for the following:

- Page views and visits
- The paths of the pages viewed
- The referrer
- Country
- Device type, browser and operating system
- Page load time and Core Web Vitals

## Cookies and tracking in Cloudflare Web Analytics

According to Cloudflare, Cloudflare Web Analytics:

- does not use any client-side state, such as cookies or localStorage, to collect its metrics;
- does not fingerprint individuals by IP address, User Agent string or any other data when measuring Core Web Vitals;
- does not track individual visitors across the sites of Cloudflare's customers.

## Cloudflare's bot detection and cf_clearance

Cloudflare, which serves this site, inserts a bot detection script (JavaScript Detections) into every page. The script uses signals from the browser to judge whether a visit is automated, that is, made by a bot. Cloudflare stores the result in a cookie named `cf_clearance`, which Cloudflare sets.

According to Cloudflare, the result on its own blocks nothing; a site owner must create a rule that uses it. This site has no such rule, so no visit is blocked because of the result.

## What this site itself stores

This site itself sets no cookies.

When you switch between the light and dark colour schemes with the colour scheme button, the site saves your choice in your browser's localStorage under the name `colorscheme`. It stays in your browser and is not sent anywhere.
